# 用户组成员筛选部门：完整目录、逐级加载与搜索

`GET /api/v1/groups/member-department-options` 为用户组页面提供部门选项。需要完整业务会话及 `identity.groups:WRITE`，不要求通用部门管理权限。返回范围由服务端当前 GroupScope 确定：内置部门管理员可查询全企业，普通角色为本部门及全部下级部门。

## 查询参数

| 参数        | 类型                | 规则                                                                                                   |
| ----------- | ------------------- | ------------------------------------------------------------------------------------------------------ |
| `mode`      | `FULL` / `CHILDREN` | 可选，省略为 FULL。FULL 返回当前组域范围的完整扁平部门目录，CHILDREN 按层返回。                        |
| `parent_id` | 规范 UUID           | 可选，仅 CHILDREN 可用。省略返回可见根；指定后返回其可见直接子部门，不含父部门及更深后代。             |
| `search`    | string              | 可选，最多 128 个 Unicode 字符；去除首尾空白后为空则不搜索。非空时仅 FULL 可用，且不能携带 parent_id。 |
| `locale`    | string              | 可选，沿用用户语言偏好、系统默认和实体名称回退。                                                       |

参数值必须完整，显式空值和重复的 mode/parent_id 拒绝；parent_id 不接受字符串 null 或用空字符串表示根。含 NUL、重复或超长 search 返回 400；tab、换行等首尾空白仍按 TrimSpace 处理。前端首次加载直接省略 parent_id。

## 返回字段与调用顺序

成功响应沿用 `code/data/params/request_id` 外壳，`data.items` 中每项固定包含：

| 字段           | 含义                                                                                 |
| -------------- | ------------------------------------------------------------------------------------ |
| `id`           | 部门 UUID，作为选项值和后续展开的 parent_id。                                        |
| `parent_id`    | 可见父部门 UUID；当前可见根为 null，不泄露范围外真实父部门。                         |
| `display_name` | 当前语言的部门显示名。                                                               |
| `has_children` | 是否存在当前可见范围内的直接子部门，false 时不显示展开入口。                         |
| `matched`      | 本次非空 search 是否直接命中此节点；仅用于补齐祖先路径的节点及无搜索查询均为 false。 |

1. 首次加载：`GET /api/v1/groups/member-department-options?mode=CHILDREN`。全局组范围返回组织根；普通子树范围返回操作者本部门这个可见根。
2. 展开节点：`GET /api/v1/groups/member-department-options?mode=CHILDREN&parent_id=<节点UUID>`。按 sort_order、id 排序，一次返回该层全部直接子节点，不分页或截断。
3. 可见叶子返回成功及 `items: []`。加载失败不得标记为叶子或覆盖为成功空结果。
4. 若需要一次性构树，省略 mode 或传 FULL。无搜索完整模式沿用原 id 排序，前端按 parent_id 建树；所有模式使用相同的五字段结构。

父节点展开结果按当前账号、组域范围、语言及 parent_id 隔离缓存；切换账号、角色、权限或部门后清理目录缓存和迟到响应，部门结构变化后重新加载相关节点。has_children 为该次查询的事实，不保证后续组织结构不变。

## 部门搜索

`GET /api/v1/groups/member-department-options?mode=FULL&search=<URL编码后的关键词>` 在当前组域全部允许部门中搜索。省略 mode 时同样为 FULL。匹配原始部门 name 或当前语言回退后的 display_name，不区分大小写，采用字面包含；百分号、下划线和反斜杠不作为通配符，不搜索描述或所有语言译文。

返回直接命中的部门及其当前可见祖先路径，去重后按相对于可见根的 depth、sort_order、id 排序。不自动展开命中部门的全部后代。当前可见根 parent_id 为 null，不回传范围外祖先；无命中返回成功及 items 空数组。has_children 仍按完整可见范围计算，不能用搜索结果里是否存在子项代替。

前端输入关键词时切换为 FULL 搜索并移除 parent_id，通过 matched 高亮直接命中；清空关键词后恢复 CHILDREN 浏览。搜索结果单独缓存，不能将筛选后的子节点集合标记为已完整加载的普通层级。若要从命中部门继续展开，先移除 search，再使用 CHILDREN 和该节点 ID 请求。

## 用户筛选

“全部部门”为前端选项，选中后不向成员查询接口传 department_id。树节点选中后：

- 组内成员：`GET /api/v1/groups/{group_id}/members?department_id=<节点UUID>`。
- 添加成员候选：`GET /api/v1/groups/{group_id}/member-options?department_id=<节点UUID>`。
- 新建组初始成员候选：`GET /api/v1/groups/initial-member-options?department_id=<节点UUID>`。

这三处 department_id 均筛选所选部门及全部下级部门。目录按层加载不改变用户筛选深度。切换筛选时重置页码或游标，保留既有搜索等合法条件。

## 失败处理

| HTTP / code             | 情况                                                                                           |
| ----------------------- | ---------------------------------------------------------------------------------------------- |
| 400 / MALFORMED_REQUEST | parent_id 格式不合法、显式空 mode/parent_id、重复参数，或 search 含 NUL、超过 128 个字符。     |
| 422 / VALIDATION_FAILED | mode 非 FULL/CHILDREN，FULL 同时提供 parent_id，或非空 search 与 CHILDREN/parent_id 同时提供。 |
| 404 / NOT_FOUND         | parent_id 不存在或不在当前可见范围，统一返回，不区分对象是否存在。                             |
| 403 / FORBIDDEN         | 当前账号没有用户组写权限。                                                                     |

parent_id 只是展开位置，不是权限根。所有请求仍按当前会话和当前授权范围重新校验；前端不能用已缓存节点替代后端授权。
