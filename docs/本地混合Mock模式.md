# 本地混合 Mock 模式

## 启动与范围

运行 `npm run dev`：登录、会话、真实权限和已实现接口继续通过 Vite 代理访问后端；项目、项目成员、项目预算、预算工单、消费账单、部门/用户预算及费用明细由开发服务处理。`npm run dev:mock` 保持原有完整 Mock 模式。

分流入口为 `mock/_hybridPlugin.ts`，只在开发服务中注册，生产构建不会注册这些中间件。不通过“后端失败后返回假成功”的方式降级；本地模块使用明确的路由白名单。

2026-11-13 已检查后端 `/openapi.json`：上述项目、成本和预算业务接口尚未发布。真实接口发布后应移除对应本地分流，按正式契约对接。

## 身份与数据隔离

- 真实账号仍使用后端 Cookie 登录。访问本地业务前由开发服务核验真实认证上下文、FULL/READY 门禁及能力权限，写请求继续检查真实 CSRF。
- 经用户明确授权，仅在本地给真实会话的权限快照增加个人工单能力与导航；不写入后端角色、能力或菜单。
- 本地项目沿用真实登录用户 ID 关联成员及申请人，使用隔离的原型 Mock 组织和成员样例。真实权限范围根节点与本地组织根节点之间只在本地业务请求中映射，不修改真实部门。首次进入时将当前账号加入“总部知识助理”演示项目。
- 真实用户列表继续读后端，只在开发服务响应中叠加共享 Mock 的项目引用；用户创建、编辑、删除等接口不被模拟，也不会因模拟审批账号而转发到后端。
- 本地响应带 `X-AIS-Local-Mock: true`，可在浏览器网络面板识别。

## 模拟审批

用不同浏览器会话登录 `local_approver_1`、`local_approver_2`。密码读取本机 `mock/accounts.json` 中 `mock_admin` 的现有密码，代码、文档不复制其值。

这两个账号只在混合开发服务中临时创建，不是后端账号；登录从 `/auth/local-mock-login` 进入本地认证，登录成功后直接进入工单管理。审批账号仅获得本地个人工单能力，其请求不会转发到真实业务接口。不支持通过模拟账号修改真实用户、角色或其他真实数据。

审批候选只有这两个显式模拟账号。工单提交后的 `steps` 决定实际审批顺序；分别登录对应账号，在“工单管理 → 待我审批”中处理。

## 共享状态与生命周期

项目、成员、项目预算台账、工单、费用记录和账单复用 `mock/_runtime.ts` 的进程级共享状态及现有处理器。账单和部门/用户预算在开发模式下也改为服务端共享状态，不再读浏览器独立副本。

成员重复添加不重复计数；预算配置、审批执行、历史及项目详情读同一台账；账单和费用明细保留项目 ID 关联。页面刷新、跨页及不同本地审批会话读取同一结果。数据在开发服务进程内保留，重启服务会恢复样例，不写真实后端，也不迁移此前浏览器里的独立演示数据。

## 验证入口

| 入口                                     | 操作                                     | 预期                             |
| ---------------------------------------- | ---------------------------------------- | -------------------------------- |
| `/identity/projects`                     | 真实账号创建项目，添加相同成员两次，刷新 | 项目可搜索，成员只增加一次       |
| `/identity/users`                        | 查询当前真实用户                         | 项目列包含本地新增项目           |
| `/cost/budgets`、`/account/projects/:id` | 配置项目预算后交叉读取                   | 金额、周期和成员一致             |
| `/personal/work-orders`                  | 提交项目预算申请，两位模拟账号按步骤审批 | 最终执行成功，预算及历史同步更新 |
| `/cost/bills`、`/cost/expenses`          | 查看账单及项目费用                       | 共用项目关联和费用记录           |
| 模拟审批会话                             | 请求真实用户写接口                       | 返回 FORBIDDEN，不转发后端       |
